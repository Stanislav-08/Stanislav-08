# 💫 About Me:
I'm a full-stack and embedded developer turning ideas into open-source code and working prototypes. Whether I'm building responsive web and desktop apps or wiring up custom microcontroller builds, I love taking projects from raw logic to working reality.<br><br>I work mostly with C#, Python, and SQL on the software side, and microcontrollers and circuit prototyping on the hardware side. Right now, I'm focused on building interactive web platforms, desktop tools, and compact desktop robotics.<br><br>If my repos help you out or inspire your own projects, feel free to buy me a coffee to fuel the next build!
